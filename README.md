# FATED

A single-file, Doom-inspired first-person shooter that runs in the browser, built on three.js (inlined, no external requests).

**Play:** `index.html` is the whole game. Open it in a modern browser, or host it with GitHub Pages (Settings > Pages > Deploy from branch > `main` / root).
